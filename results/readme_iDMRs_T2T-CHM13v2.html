Description

This track presents maternal-versus-paternal differentially methylated regions (DMRs) identified using HPRC release v2 assemblies. Analyses included 123 samples for autosomes and 50 female samples balanced for the inferred X inactivation status.

Display Conventions and Configuration

Regions are colored according to the direction and magnitude of the methylation difference, calculated as maternal minus paternal methylation:

  • Red: Strong maternal hypermethylation (methylation difference ≥ 0.15).
  • Pink: Moderate maternal hypermethylation (0 < methylation difference < 0.15).
  • Light blue: Moderate paternal hypermethylation (-0.15 < methylation difference < 0).
  • Blue: Strong paternal hypermethylation (methylation difference ≤ -0.15).

Positive differences indicate higher methylation on the maternal haplotype, whereas negative differences indicate higher methylation on the paternal haplotype.

Methods

Read Alignment and Methylation Processing

Assemblies and Oxford Nanopore Technologies (ONT) sequencing data for 123 samples were downloaded from the HPRC AWS bucket. ONT reads carrying methylation tags were aligned to the corresponding personalized diploid assemblies using Winnowmap v2.03 with the parameters -x map-ont -I 8G --MD --cs -y -a -Y -L --eqx. Only primary alignments were retained. Methylated read counts and total coverage at individual CpG sites were obtained using modkit v0.4.1.

Coordinate Conversion

Each diploid assembly was separated into its two haplotypes. Haplotype-to-CHM13v2.0 alignments and chain files were generated using nf-LO and minimap2. Methylation calls were lifted over to CHM13v2.0 using CrossMap v0.7.0. Negative-strand coordinates were adjusted by −1 bp to place calls on the cytosine of the corresponding CpG.

Chromosome X Sample Selection

For chromosome X, samples were classified according to which parental haplotype showed greater overall X inactivation. Mean XIST promoter methylation was calculated for each haplotype. A positive maternal-minus-paternal difference indicated preferential paternal X inactivation, whereas a negative difference indicated preferential maternal X inactivation.

Among 59 female samples, 34 were classified as having preferential paternal X inactivation and 25 as having preferential maternal X inactivation. Chromosome X analysis included all 25 samples with preferential maternal X inactivation and 25 randomly selected samples with preferential paternal X inactivation.

Differential Methylation Analysis

Differential methylation analysis was performed by chromosome using DSS v2.58.0 in R v4.5.3. Methylated read counts and total coverage were extracted separately for maternal and paternal haplotypes across 123 samples for autosomes and 50 samples for chromosome X, and combined into a BSseq object. CpG sites with missing methylation data in more than 5% of samples were excluded.

A paired design was used to account for inter-sample variability, with sample identity included as a fixed effect. Models were fitted using DMLfit.multiFactor() with the formula ~ haplotype + sample. Haplotype-associated methylation differences were evaluated using DMLtest.multiFactor(), which applies a Wald test to the haplotype term.

DMRs were identified using callDMR() with a P-value threshold of 0.001 and otherwise default parameters.

DMR Consolidation and Classification

To consolidate neighboring DMRs potentially representing the same imprinted region, DMRs separated by no more than 1,000 bp were merged if they showed the same direction of maternal-versus-paternal methylation differences. This reduced the number of regions from 1,509 to 880.

Regions were classified as showing strong methylation differences if the absolute maternal-versus-paternal difference was at least 0.15, and moderate differences if it was below 0.15. Colors were assigned according to this classification and the hypermethylated parental haplotype.

Data Format

The tab-delimited region file contains the following columns:

  1. chrom: Chromosome name.
  2. chromStart: Start coordinate, 0-based and inclusive.
  3. chromEnd: End coordinate, exclusive.
  4. name: Hypermethylated haplotype.
  5. score: Methylation difference between maternal and paternal haplotypes (maternal minus paternal).
  6. strand: A period (.), indicating that strand is not specified.
  7. thickStart: Same as chromStart.
  8. thickEnd: Same as chromEnd.
  9. itemRgb: Region color, indicating the direction and magnitude of the methylation difference:
    • #FF0000: Strong maternal hypermethylation.
    • #E78080: Moderate maternal hypermethylation.
    • #8484FC: Moderate paternal hypermethylation.
    • #0000FF: Strong paternal hypermethylation.
