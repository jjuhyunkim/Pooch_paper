Description

This track shows the mean difference in CpG methylation between maternal and paternal haplotypes across samples, using HPRC release v2 assemblies (n=123 for autosomes and n=50 for chromosome X). Differential methylation was calculated as maternal minus paternal methylation. Positive values indicate higher methylation on the maternal haplotype, whereas negative values indicate higher methylation on the paternal haplotype. Coordinates are based on the GRCh38 reference genome.

Methods

Read alignment and methylation processing

Assemblies and Oxford Nanopore Technologies (ONT) sequencing data for 123 samples were downloaded from the HPRC AWS bucket. ONT reads carrying methylation tags were aligned to the corresponding near-T2T, trio- and Hi-C-phased diploid assemblies using Winnowmap v2.03 with the following parameters: -x map-ont -I 8G --MD --cs -y -a -Y -L --eqx. Only primary alignments were retained. Methylation calls were obtained using modkit v0.4.1.

Coordinate conversion

Each diploid assembly was separated into its two haplotypes. Haplotype-to-CHM13v2.0 alignments and chain files were generated using nf-LO and minimap2. Methylation calls were lifted over to CHM13v2.0 using CrossMap v0.7.0. Negative-strand coordinates were adjusted by −1 bp to place calls on the cytosine of the corresponding CpG.

Differential methylation

For each CpG site in each sample, methylation fractions were calculated for the maternal and paternal haplotypes as methylated-read coverage divided by total coverage. CpG sites with more than 5% missing values across samples were excluded. For each remaining site, the maternal-minus-paternal methylation difference was calculated within each sample. These per-sample differences were then averaged across samples to generate the track.

Chromosome X Sample Selection

For chromosome X, samples were classified according to which parental haplotype showed greater overall X inactivation. Mean XIST promoter methylation was calculated for each haplotype. A positive maternal-minus-paternal difference indicated preferential paternal X inactivation, whereas a negative difference indicated preferential maternal X inactivation.

Among 59 female samples, 34 were classified as having preferential paternal X inactivation and 25 as having preferential maternal X inactivation. Chromosome X analysis included all 25 samples with preferential maternal X inactivation and 25 randomly selected samples with preferential paternal X inactivation.

Transfer to GRCh38

The CpG methylation difference track was lifted over from CHM13v2.0 to GRCh38 using CrossMap with the chm13v2-grch38.chain chain file.
